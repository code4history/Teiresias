# Project Context

## Purpose
Teiresias orchestrates CRS estimation for Maplat V3.1 from GCPs and a supplied candidate CRS set.

## Tech Stack
- TypeScript (planned)
- Node.js and browser runtimes

## Domain Context
- Candidate CRS lookup is external.
- Single-CRS world-file fitting is external.
- Teiresias coordinates those pieces to choose the best CRS and final world-file parameters.
