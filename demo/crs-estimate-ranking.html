なぜ y 軸を反転すると識別力が潰れるのか。 Daedalus の basic fit は相似変換（回転・等方スケール・平行移動）であり、 鏡映を表現できない。∴ pixel の y を反転させると、どの候補 CRS でも 同じくらい当てはまらなくなる ∴ 候補間の残差の差が消える。 これは Teiresias のバグではなく、world file を相似変換で当てる限り構造的にそうなる、という 観測可能な事実である。

識別力は rms[2位] / rms[1位] で表示している。反射なしでは真値が厳密適合するため 比が巨大になり、反射ありでは 1.0 付近へ落ちる。候補を catalog（既定カタログ全件）にすると、反射ありでは真値が 1 位から転落する様子も見える。
